Architecture · NFL Events Hub on EDS

NFL Events Hub — high-level architecture

01 · Public view

Browse & buy

Hub, event listing and event pages are static EDS pages from the CDN. No pricing, no card payments. Paid events show Buy Tickets, an authored Ticketmaster link that leaves the hub.

02 · NFL ID

Login & register

Log in and Register both open the hosted id.nfl.com screens, identical to OnePass. The middleware completes sign-in and sets an HttpOnly session cookie. Inside OnePass the app hands its session over, so there is no second login.

03 · Registration

Register for an event

Every event has a Register button. A form block renders fields authored per event in a sheet (watch parties, free events). Submit goes to /api/register with the fan’s NFL ID, never to a public endpoint.

04 · Logged-in view

My events

Same cached pages; blocks call /api/me and /api/my-events to show registered events, status, a QR code and Add to Wallet (pass signed server-side by /api/wallet).

05 · OnePass app

In-app experience

OnePass opens the same pages in app mode: no site header/footer, native back, share and wallet via a small JS bridge. FanScan check-ins stay native.
