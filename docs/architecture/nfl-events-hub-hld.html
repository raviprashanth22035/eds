NFL Events Hub — high-level design

  1. Clients. NFL OnePass and the NFL App open the hub in a WebView; the web is nfl.com and club sites. One portal for all three.
  2. Edge. DNS → CDN. The CDN serves cached pages to everyone and sends only /auth and /api to the edge worker.
  3. Platform we build. The NFL Events Hub on AEM Edge Delivery (authored by clubs and the league), a thin stateless edge worker, and one event registration service with its own database: registration, capacity, QR codes, check-in and wallet passes.
  4. NFL & partners. NFL ID for sign-in, NFL notifications (email, app push) for confirmations and cancellations, Apple / Google Wallet for passes.
  5. Partners. Paid events link out to Ticketmaster (VIP via On Location). No payments in the hub.
  6. Operations. GitHub → code sync → preview → live; WAF and bot rules at the CDN; AEM telemetry and logs. The only data we hold is in the registration service’s managed database.
