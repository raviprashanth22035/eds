NFL Events Hub — high-level design

  1. Clients. NFL OnePass and the NFL App open the hub in a WebView; the web is nfl.com and club sites. One portal for all three.
  2. Edge. DNS → CDN. The CDN serves cached pages to everyone and sends only /auth and /api to the edge worker.
  3. Platform we build. The NFL Events Hub on AEM Edge Delivery (authored by clubs and the league) and a thin edge worker: stateless, no database.
  4. NFL services. NFL ID for sign-in; the OnePass event platform owns registrations, QR, wallet passes and notifications.
  5. Partners. Paid events link out to Ticketmaster (VIP via On Location). No payments in the hub.
  6. Operations. GitHub → code sync → preview → live; WAF and bot rules at the CDN; AEM telemetry and logs. No servers, VPCs or databases to run.
